# v0.1.0

首个正式版，支持 Key 跟随关联 Codex 账号的周额度重置。

- 重新整理关联列表，分别显示 Key 用量、账号使用百分比、账号预计重置和状态；统一金额精度，移除进度条与重复邮箱。
- 新增设置页面，集中管理提前重置开关和显示时区。时区支持跟随浏览器、北京时间和 UTC。
- 简化页面说明与操作布局，适配明暗主题和窄屏；README 更新为实际新版截图和简明安装说明。

支持官方 Codex Proxy RS v3.18.3、Linux x86_64 / ARM64。从 beta 更新保留原有关联、暂停状态、待处理记录和提前重置设置，升级本身不会清零。显示时区默认跟随浏览器。

Key 自身的周窗口仍由宿主独立计算，可能早于账号窗口重置；未知清零结果不会自动重试。真实自然换周与长期运行稳定性不包含在本次验证范围内。
